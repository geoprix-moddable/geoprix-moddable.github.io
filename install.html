Install

Get GeoPrix Moddable running and add mods to it. No root needed.

  1. Install GeoPrix Moddable

    Install the GeoPrix Moddable build (game version 3.3) on your Android phone. It replaces the normal GeoPrix app, so uninstall that first if Android asks.

  2. Get a mod

    Download a .gpmod file for the mod you want. See the mods list.

  3. Open the mods folder

    In GeoPrix go to Settings > MODS > OPEN MODS FOLDER. This opens the Files app at GeoPrix Mods.

  4. Copy the mod in

    Copy the .gpmod file from your Downloads into GeoPrix Mods.

  5. Switch it on and restart

    Back in the game the mod shows up in the Mods list. Switch it on and tap RESTART.

Good to know

Restart after changes

Mods only load when GeoPrix starts, so turning one on or off, or adding or deleting a file, needs a restart.

Updating a mod

Delete the old version in the Mods screen (long-press) first. Otherwise the copy is saved as name (2).gpmod.

Phone vs emulator

Every mod runs on a real arm64 phone. On an emulator, mods that use method hooks run with those parts turned off.
