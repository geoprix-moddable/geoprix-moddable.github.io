Make mods

A GeoPrix mod is Java code the game loads when it starts. Mods can add Settings buttons, keep their own saved data, call game classes and, on a real phone, hook game methods.

Quick start

  1. Copy the example

    Copy modding/examples/hello-screen/ to a new folder, for example modding/my-mod/.

  2. Edit it

    Give mod.json your own id and main class, then change the Java code in src/.

  3. Build it

    Run the build script. The output is build/mods/<id>.gpmod.

  4. Test it

    Copy the file into GeoPrix Mods, switch it on and restart. See Install.

bash modding/build_gpmod.sh modding/my-mod

What you need

JDK 11+

javac and jar to compile the mod.

Android SDK

platforms/android-34 and any build-tools for d8.

Python + Bash

Python reads the id from mod.json. On Windows use Git Bash.

The .gpmod file

A .gpmod is a zip file with these parts:

FileWhat it is
mod.jsonName, version, entry class and other details
classes.dexYour compiled code (min API 28)
assets/…Optional. Your own images, sounds or JSON, read with ctx.openAsset(path)
lib/<abi>/*.soOptional. Native libraries; ship arm64-v8a

mod.json

{
  "id": "yourname.coolmod",
  "name": "Cool Mod",
  "version": "1.0",
  "author": "You",
  "description": "What it does.",
  "type": "Code Mod",
  "main": "yourname.coolmod.CoolMod",
  "needsHooks": false
}

Set needsHooks to true only if the mod changes game methods. Hooks run on real arm64 phones only, not on x86_64 emulators.
